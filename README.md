# 🛒 Online Retail Database Management System

A complete **SQL Server Database Management System** project that simulates a real-world online retail platform. This project demonstrates database design, normalization, relationships, constraints, indexing, views, triggers, stored procedures, advanced SQL queries, and Role-Based Access Control (RBAC).

Designed as a portfolio project for Software Developer, Database Developer, and Data Engineer roles.

---

## 📌 Project Overview

The Online Retail Database Management System manages the core operations of an e-commerce platform, including:

* Customer Management
* Product Management
* Category Management
* Order Processing
* Inventory Management
* Sales Analysis
* Audit Logging
* User Access Control

The project follows industry-standard SQL Server practices and includes automation using triggers and stored procedures.

---

# 📂 Database Schema

The database consists of six main tables.

| Table      | Description                                |
| ---------- | ------------------------------------------ |
| Categories | Stores product categories                  |
| Customers  | Stores customer information                |
| Products   | Stores product details and inventory       |
| Orders     | Stores customer orders                     |
| OrderItems | Stores products included in each order     |
| AuditLog   | Stores activity logs generated by triggers |

## Views

Three reusable views are included.

### `vw_OrderDetails`

Displays complete order information including:

* Customer
* Product
* Category
* Quantity
* Price
* Order Status

---

### `vw_CustomerOrderSummary`

Provides customer-level analytics.

Includes:

* Total Orders
* Total Spending

---

### `vw_ProductSales`

Provides product performance statistics including

* Units Sold
* Revenue Generated
* Category

---

# ⚡ Triggers

The project includes multiple business automation triggers.

### Stock Management

Automatically reduces product stock whenever an order item is inserted.

---

### Order Total Calculation

Automatically recalculates the order total whenever:

* Order Item Added
* Updated
* Deleted

---

### Customer Audit

Automatically records newly registered customers into the Audit Log.

---

### Business Rule Enforcement

Prevents inventory from becoming negative.

# 🔐 Role-Based Access Control (RBAC)

The project implements SQL Server security using custom roles.

### Admin

* Full database access

### Sales

* Manage Orders
* Manage Order Items
* Read Products
* Read Customers

### Analyst

* Read-only access
* Reporting Views
* No Audit Log Access

# 🚀 How to Run

1. Open **SQL Server Management Studio (SSMS)**.
2. Create a new query window.
3. Open the SQL script.
4. Execute the script from top to bottom.
5. The database, tables, data, indexes, views, triggers, roles, and stored procedures will be created automatically.
